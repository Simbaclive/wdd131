Site Planning Document

Project: Local Tech Community Hub

1. Site Name

Name: Metro Tech & Coding Hub

Description: This name represents a community-focused platform designed to connect local developers, students, and technology professionals for collaboration, mentorship, and continuous learning.

Optional Domain Availability: metrotechhub.org

2. Site Purpose

The site serves as a central resource hub for regional technology enthusiasts. It provides information on upcoming coding bootcamps, tech meetups, resource guides for software development languages, and a contact/membership sign-up form.

3. Scenarios

  • Where can I find information about the next local developer meetup?
  • How do I sign up to become a mentor or join the community newsletter?

4. Color Schema

Our carefully selected color palette provides a clean, professional, and accessible look and feel:

  • Primary Color (#1b4332 - Deep Forest Green): Used for headers, footers, and primary button backgrounds.
  • Secondary Color (#2d6a4f - Medium Green): Used for navigation highlights and section borders.
  • Accent Color (#52b788 - Soft Mint): Used for call-to-action highlights and interactive elements.
  • Background Color (#f8f9fa - Light Off-White): Used for main page backgrounds to ensure high contrast and readability.

5. Typography

We use up to two web-safe fonts to maintain visual hierarchy and clean design:

  • Heading Font (Segoe UI, sans-serif): Used for all page titles, major headings, and section headers.
  • Body Font (Roboto, Arial, sans-serif): Used for paragraphs, navigation links, list items, and standard body text.

6. Wireframes

Below are the structural layouts for the mobile and desktop views of the home page.

Mobile View Layout

  • Single-column vertical stack
  • Header with logo and hamburger menu
  • Hero banner image
  • Stacked content cards
  • Footer with copyright details

Desktop View Layout
